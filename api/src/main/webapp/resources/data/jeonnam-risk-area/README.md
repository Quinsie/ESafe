# Jeonnam Approximate Risk Area

이 폴더는 공식 행정경계가 아닌, 광주/전라남도 시군구 건물 점 분포를 바탕으로 만든 시각화용 간이 영역 데이터를 저장한다.

- 입력 원본: `api/.local-seed/data-h2.full.sql`
- 생성 스크립트: `api/scripts/generate_jeonnam_sig_approx_geojson.py`
- 출력 파일: `jeonnam-sig-approx-risk.geojson`

주의:
- 이 데이터는 공식 시군구 경계가 아니다.
- 지도 가독성을 위한 근사 영역이다.
